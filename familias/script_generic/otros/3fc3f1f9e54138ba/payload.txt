              <div class="docs-panel__title">
                <h2 class="docs-panel__title-name">Install Plesk on Your Server<a id="install-plesk-on-your-server"
                                                                                  href="#install-plesk-on-your-server"
                                                                                  class="anchor"></a></h2>
              </div>

              <div class="docs-panel__content">
                <p>Get some hands-on experience with the latest stable Plesk release.</p>

                <h3>Plesk on a physical server or VM<a id="plesk-on-a-physical-server-or-vm"
                                                       href="#plesk-on-a-physical-server-or-vm" class="anchor"></a></h3>
                <p>The easiest way to install Plesk on your physical server or virtual machine running Linux is to <a
                    href="https://get.plesk.com/" target="_blank">use our Web Installer</a>.</p>
                <p>More of a Windows fan? <a href="https://installer-win.plesk.com/plesk-installer.exe" target="_blank">Download
                  the Windows Installer</a> and run the following command:</p>
                <pre id="plesk-windows" class="docs-panel__code">plesk-installer.exe --select-product-id=panel --select-release-latest --installation-type=typical</pre>
                <p><a class="copy-link" data-clipboard-target="#plesk-windows">click to copy to clipboard</a></p>
                <p>Plesk is installed with a full-featured 14-day trial license. Always install Plesk on a fresh server,
                  and make sure to <a href="https://docs.plesk.com/release-notes/current/software-requirements/"
                                      target="_blank">read the software requirements</a> before installation.</p>

                <h3>Plesk in the cloud<a id="plesk-in-the-cloud" href="#plesk-in-the-cloud" class="anchor"></a></h3>
                <p>Do not have a server? <a href="https://docs.plesk.com/cloud/" target="_blank">Many cloud
                  providers</a> offer Plesk images in their marketplaces. It is a great way to quickly deploy a server
                  with Plesk pre-installed.</p>

                <h3>Plesk in Docker<a id="plesk-in-docker" href="#plesk-in-docker" class="anchor"></a></h3>
                <p>Plesk in Docker is great for developers looking to create <a
                    href="https://docs.plesk.com/en-US/current/extensions-guide/plesk-extensions-in-a-nutshell.76331/"
                    target="_blank">an extension for Plesk</a>, or as a local dev environment.</p>
                <p>To run Plesk in Docker, follow these steps:</p>
                <ol>
                  <li>
                    <a href="https://www.docker.com/get-started" target="_blank">Download and install Docker</a> on your
                    laptop/desktop.
                  </li>
                  <li>
                    <p>Once Docker is installed and running, run the following command:</p>
                    <pre id="plesk-docker" class="docs-panel__code">docker run -d -p 80:80 -p 443:443 -p 8880:8880 -p 8443:8443 -p 8447:8447 plesk/plesk</pre>
                    <p><a class="copy-link" data-clipboard-target="#plesk-docker">click to copy to clipboard</a></p>
                  </li>
                  <li>
                    Access Plesk in your browser using the Docker host IP address and port 8880 (e.g.
                    <code>https://192.0.2.2:8880</code>). The default administrator credentials are <code>admin</code> / <code>changeme</code>.
                  </li>
                </ol>
                <p><a href="https://hub.docker.com/r/plesk/plesk/" target="_blank">You can also find Plesk on Docker
                  Hub!</a></p>

                  Try the Online Demo<a id="try-plesk-online-demo" href="#try-plesk-online-demo" class="anchor"></a>

              </div>

              <div class="docs-panel__content">
                <p>The easiest and commitment-free way to experience the latest stable Plesk release. Log in and give it
                  a try — the demos are full-featured.</p>
                <p>The online demo comes in two flavors:</p>
                <ul>
                  <li>
                    <b>WebPro</b> — Plesk edition targeting web professionals. Features a streamlined interface and
                    hosts up to 30 domains.
                  </li>
                  <li>
                    <b>WebHost</b> — Plesk edition for shared web hosting services. A more robust interface with support
                    for resellers, hosting plans, and unlimited domains.
                  </li>
                </ul>
                <p>Linux</p>
                <ul>
                  <li>
                    <a href="https://webpro-lin.demo.plesk.com:8443/login_up.php3?login_name=admin&passwd=panel&locale_id=en-US"

                </ul>
                <p>Windows</p>
